E-LEARNING PLATFORM WITH PERFORMANCE MANAGEMENT
================================================

Prototype type: Frontend-only HTML/CSS/JavaScript
Purpose: JNTUH AR22 Software Engineering PBL prototype

HOW TO RUN
----------
1. Extract this ZIP.
2. Open the E-Learning-Platform folder in VS Code.
3. Open index.html.
4. Use VS Code Live Server (recommended), or open index.html directly in a browser.

- Java course modules
- Quiz with score calculation
- Quiz score saved to LocalStorage
- Assignment submission demo
- Performance calculation
- Faculty dashboard
- Faculty student-performance filtering
- Responsive UI
- Consistent navigation and styling

IMPORTANT
---------
This is a frontend prototype. It does not contain a real database,
server authentication, file upload backend, or permanent multi-user
storage. Those can be added as the next development phase.
